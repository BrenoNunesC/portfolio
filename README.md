# Portfólio | Breno Nunes

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript para a disciplina de desenvolvimento web.

🔗 **Acesse:** https://brenonunesc.github.io/portfolio/

## Páginas

- **Início**: apresentação, efeito de digitação, contadores animados e áreas de atuação
- **Sobre**: quem sou eu, barras de habilidades, linha do tempo e curiosidades
- **Projetos**: cards dos meus projetos com filtro por categoria
- **Contato**: links de contato e formulário com validação

## O que foi usado

- HTML semântico (`header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `footer`, `time`)
- CSS com variáveis, Flexbox, Grid, gradientes, transições, `@keyframes` e media queries
- JavaScript manipulando o DOM:
  - menu mobile (hambúrguer)
  - tema claro/escuro salvo no `localStorage`
  - saudação conforme o horário
  - efeito de digitação
  - contadores e barras de habilidade animados com `IntersectionObserver`
  - filtro de projetos
  - curiosidade aleatória
  - validação do formulário e contador de caracteres
  - botão de voltar ao topo e ano automático no rodapé
